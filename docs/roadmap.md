# 연구 계획

## 연구 질문

동일한 FFW-SG2·시연 데이터·평가 조건에서 policy 선택이 빨래 접기의 자율 성공률, 완료 시간, 수동 개입, 실패 유형에 어떤 영향을 주는가?

## 단계별 완료 기준

- [x] 공개 GitHub 저장소와 실험 기록 양식 준비
- [ ] **장비 확인:** 실제 설치 버전, 카메라, joint 순서·단위·제어 주기, 학습 장비 기록
- [ ] **작업 정의:** 첫 의류·접기 방식·초기 상태·성공 기준 고정
- [ ] **시연 수집:** 동기화된 관측/행동 기록, 에피소드 메타데이터, train/validation/test manifest 확인
- [ ] **첫 baseline:** 기능 확인 실험과 실패 분석 완료
- [ ] **첫 학습 policy:** 고정된 데이터로 학습하고 별도 평가 결과 기록
- [ ] **policy 비교:** 같은 평가 세트와 사전 정의한 예산으로 두 개 이상 비교
- [ ] **확장:** 의류·배치·소재 변화, 장기 동작, 일반화 평가

## 첫 실험 제안

`EXP-001`: 펼친 직사각형 수건을 한 번 접기. 작업 자체가 가능한지 확인한 뒤 시연 데이터를 수집하고, baseline과 첫 학습 policy를 비교합니다. 의류 전체를 정리하는 작업으로 확장하기 전에 관측·행동 기록과 평가가 일관되게 작동하는지 확인합니다.

작업과 policy 선택은 아직 확정되지 않았습니다. [실험 프로토콜](experiment-protocol.md)의 20회 시작 실험은 파이프라인 확인용이며, 본 비교의 표본 수는 별도로 정합니다.
